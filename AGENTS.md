# Agent guide

Read [docs/CONTEXT.md](docs/CONTEXT.md) before making a non-trivial change. It is the short current-state map; use [docs/README.md](docs/README.md) to find deeper canonical documentation.

For source changes, follow the end-of-task checks in [CLAUDE.md](CLAUDE.md). For risk, TDD, review, and documentation expectations, follow [docs/QUALITY-AND-DELIVERY.md](docs/QUALITY-AND-DELIVERY.md).

Do not treat historical plans, migration notes, or the `nextapp/` reference scaffold as the current implementation contract.
